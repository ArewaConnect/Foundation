BOTAS Photo — Location Management

Add locations in order. Serial codes are generated automatically and saved in Firestore. Existing codes are never renumbered. Enter one name per line when adding multiple locations.

1. States

2. Local Governments

3. Wards

4. Polling Units (P.U.)

Code format: State (2 digits) + LGA (2 digits) + Ward (2 digits) + Polling Unit (3 digits). Example: 06 04 01 001. The serial codes are scoped to their parent location.
